# Multivariate analysis of genetic and phenotypic variance-covariance matrices

Comparing simulated genetic and phenotypic variance-covariance matrices.

## Workflow

1. Generate pedigree
2. Generate phenotypes along pedigree (phensim)
3. Estimate G matrix (WOMBAT)
4. Compare G, A, and P

Running main.r (with `Rscript main.r`) will save matrices in the main directory as a CSV file, *title*_matrices.csv. G is the estimated G matrix from WOMBAT, A is the covariance matrix of breeding values returned by phensim, and P is the covariance matrix of phenotypes returned by phensim. These matrices can be read into R using /util/read_matrices.R.

figures.RMD contains code to generate ggplot figures from the matrices.csv file.

## Dependencies

- R with tidyverse, MCMCglmm, mixtools, monomvn, here, Matrix, evolvability, evolqg, and reshape2
- WOMBAT (http://didgeridoo.une.edu.au/km/wombat.php) in the system path as 'wombat'
- UNIX-like system (Linux, macOS, WSL on Windows)

## Directories

### /util/

This directory contains utility scripts for the project. These functions input lists of matrices and output relevant statistics as a dataframe.

### /temp/

This directory contains temporary files generated by the scripts. These files are not tracked by git. WOMBAT output is saved here during simulation runs. *Must manually create /temp/ if it does not exist.*
